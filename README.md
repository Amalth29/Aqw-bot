# AQW Verification Bot

A test bot made by Ajorde

## Features
- Button-based verification
- Modal username input
- Role management
- Logging system
- Clean embed UI

---

## Setup

### 1. Install dependencies
npm install

### 2. Configure .env
TOKEN=your_bot_token
VERIFY_CHANNEL_ID=channel_id
LOG_CHANNEL_ID=channel_id

### 3. Run bot
npm start
